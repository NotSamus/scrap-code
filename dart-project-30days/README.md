# Dart Project - 30 Days

This repository is a personal playground for learning the **Dart** programming language by building small command-line projects.

It is based on the **#DartProjects** series by [Appwriters](https://www.appwriters.dev/), a "30 projects in 30 days" challenge where each project teaches a new Dart concept step by step. For more info, check out:

- [Appwriters Dart Projects index](https://www.appwriters.dev/projects/dart)
- [Project 1: Temperature Converter](https://www.appwriters.dev/projects/dart/project1)

## Project Structure

Each folder holds an exercise from the series:

| Folder                     | Project               | Description                                                                                         |
| -------------------------- | --------------------- | --------------------------------------------------------------------------------------------------- |
| `0-dart_test/`             | Basics practice       | First steps with Dart: variables, lists, loops, and `print` statements (`hello.dart`)               |
| `1-temperature_convertor/` | Temperature Converter | Converts between Celsius and Fahrenheit using user input (`dart:io`) and conditionals (`temp.dart`) |
| `2-/`                      | _Coming soon_         | Placeholder for the next project                                                                    |
| `3-/`                      | _Coming soon_         | Placeholder for the next project                                                                    |

## Running the projects

Make sure the [Dart SDK](https://dart.dev/get-dart) is installed, then run any script with:

```sh
dart run 1-temperature_convertor/temp.dart
```
